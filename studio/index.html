How to make a token (once, 2 minutes)
  1. Open github.com → Settings → Fine-grained tokens → Generate new token.
  2. Name it ecem.world studio. Expiration: up to a year.
  3. Repository access: Only select repositories → ceceming/ecem.world.
  4. Permissions → Repository permissions: Contents: Read and write, and Actions: Read and write (only for the "Check Substack now" button).
  5. Generate, copy, paste above. Do this once per device.
